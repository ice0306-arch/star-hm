원본 REP와 SQLite DB는 data/hm-ai-admin 아래에만 저장됩니다.

공개 사이트에는 public/hm-ai-data의 승인 데이터만 올라갑니다.

ASL 공식 경기의 전체 REP 저장소는 공개로 운영되는 형태가 아니라서, 공개 리플레이 DB에서 후보를 수집한 뒤 검수하는 방식으로 관리합니다.

Auto Replay Collector

REP 자동 수집

리플레이 파일 URL이나 .rep 링크가 모여 있는 페이지 URL을 넣으면 자동으로 내려받아 후보 목록에 등록합니다.

직접 파일을 고르는 방식은 예외 상황용입니다. 기본 흐름은 URL 수집 → 후보 등록 → 검수 → 공개 데이터팩 생성입니다.
Replay Sources

추천 REP 출처

아래 출처는 공개 리플레이 후보를 찾기 위한 시작점입니다. “수집 URL로 넣기”를 누르면 위 자동 수집 칸에 바로 들어갑니다.

ASL Player Preset

ASL 선수 기준 자동 수집

최근 ASL/SSL에 자주 보이는 한국 선수 ID를 기준으로 공개 리플레이 DB에서 후보 REP를 찾습니다. 기본 기간은 2024년부터 2026년까지입니다.

자동 수집은 공개 DB에서 확인 가능한 후보만 가져옵니다. 선수 ID가 동명이인이거나 오래된 리플레이일 수 있으므로 분석 반영 전 검수 단계가 필요합니다.
Analysis & Learning

다운로드 후 다음 단계

수집된 REP는 바로 학습에 쓰지 않습니다. 먼저 분석기를 돌려 경기 정보, 선수별 분당 명령 수, 생산 공백, 코칭 근거를 DB에 저장합니다. 그다음 검수된 결과만 공개 데이터팩에 반영합니다.

수집 → REP 분석 → 학습 후보 검수 → 공개 데이터팩 생성 → 데이터팩 검증
