HM AI 로컬 관리자

이 화면은 공개 Vercel 사이트가 아니라 사용자 컴퓨터에서만 실행되는 REP 수집·검수·데이터팩 준비용 관리자입니다. 원본 REP, SQLite DB, 관리자 메모는 공개 사이트로 배포하지 않습니다.

DB 초기화

npm run admin:db:migrate 로 SQLite 스키마를 생성합니다.

보안

서버는 127.0.0.1에만 바인딩하고 외부 Host와 Origin 요청을 거부합니다.

공개 데이터팩

승인된 파생 데이터만 public/hm-ai-data로 내보냅니다.

상태 API

/api/dashboard 에서 로컬 테이블 상태를 확인합니다.
